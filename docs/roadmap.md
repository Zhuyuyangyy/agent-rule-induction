## Long-Term Vision

The long-term vision is an "AlphaGo-for-Science" system:

1. LLM proposes candidate theories
2. Active search designs high-information experiments
3. SymPy/Verifier enforces hard constraints
4. Benchmark suite provides reproducible evidence
5. Paper/Artifact ensures academic credibility

**But never claiming new physics without evidence.**

The path from controlled benchmarks to genuine scientific discovery remains an open challenge. Each step must be grounded in reproducible evidence and bounded by explicit claim boundaries.
